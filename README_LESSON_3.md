# Практическое задание №3 — основы ООП и Generics

## Что изменено
- Стек вынесен в пакет `stack` и обобщён: `Stack[T any]`.
- Очередь вынесена в пакет `queue` и обобщена: `Queue[T any]`.
- Односвязный список вынесен в пакет `linkedlist` и обобщён: `LinkedList[T any]`.
- Демонстрационная программа находится в `task1/main.go` и импортирует три пакета.
- Для каждой структуры добавлены тесты, в том числе проверки работы со строками.

## Запуск
Из корня проекта:

```bash
go test ./...
go run ./task1
```

Generics поддерживаются начиная с Go 1.18. В `go.mod` указана версия языка Go 1.23.0.
